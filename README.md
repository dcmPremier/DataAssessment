# DataAssessment

Definian Enterprise Data Readiness Assessment — a self-contained HTML deliverable used to evaluate an organization's data maturity across foundations, governance, analytics, and AI readiness.

## Contents

- `Definian_Enterprise_Data_Assessment.html` — standalone interactive assessment. Open directly in a modern browser; no build step or server required.

## Usage

Double-click the HTML file or serve it from any static host. All assets are bundled inline.
